# 🚨 ResQNet AI

## AI-Powered Silent Emergency Detection & Rescue Alert System

ResQNet AI is a smart emergency response system that detects dangerous situations before a victim can call for help. It combines AI monitoring, silent SOS, voice analysis, GPS location, and emergency alerts to reduce rescue response time.

## Current Implementation (Phase 1)

- Premium Landing Page
- AI Monitoring Interface
- Smart Trigger Workflow
- User Registration
- Flask Backend
- SQLite Database Integration
